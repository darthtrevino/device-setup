# device-setup

Baseline configuration for my workstations. Each platform uses its native provisioning tool; anything
that is the same everywhere lives once in [`shared/`](shared).

| Platform | Directory | Tool | Entry point |
| --- | --- | --- | --- |
| Linux (Fedora) | [`linux/`](linux) | Ansible | `sudo ./bootstrap.sh`, then `ansible-playbook playbooks/workstation.yml -K` |
| macOS | [`macos/`](macos) | Homebrew (`Brewfile`) | `./macos/bootstrap.sh` |
| Windows | [`windows/`](windows) | WinGet Configuration | `winget configure -f windows\machine.dsc.winget`, then `.\windows\bootstrap.ps1` |

## Shared configuration

| Path | What | Linux | macOS | Windows |
| --- | --- | --- | --- | --- |
| `shared/git/gitconfig` | Global git config | linked by `git` role | linked | linked |
| `shared/git/gitconfig.local.example` | Seeds `~/.gitconfig.local` once | `git` role | bootstrap | bootstrap |
| `shared/git/auth.ps1` | gh logins + per-remote git identity/credential routing (PowerShell 7) | run by hand | bootstrap | bootstrap |
| `shared/package-feeds/*` | npm/pnpm, pip, uv, NuGet → Microsoft package feed proxy ([details](shared/package-feeds/README.md)) | copied by `package_feeds` role | copied | copied |
| `shared/vscode/settings.json` | VS Code user settings | linked by `vscode` role | linked | linked |
| `shared/vscode/extensions.txt` | VS Code extensions | `vscode` role | bootstrap | bootstrap (+ `windows/vscode-extensions.txt`) |

Dotfiles are symlinked into the checkout, so edits show up in `git diff`. Package feed configs are
always copied instead, because `npm login` and `dotnet nuget add source` write credentials into them.
Existing files are kept as `*.<timestamp>.bak` before being replaced, and every entry point is safe
to re-run.

Kept **out of this repo** (per machine):

- `~/.gitconfig.local`: default git identity, Azure Repos credential blocks, `safe.directory`.
- `~/.gitconfig.gh`, `~/.gitconfig.darthtrevino`, `~/.gitconfig.emu`, `~/.gitconfig.overrides`:
  generated by `shared/git/auth.ps1`.
- `~/.vscode-extensions.local.txt` (optional): private/internal VS Code extensions, one ID per line.

## Git identities and GitHub accounts

| Remote | Identity | Token (`gh auth token --user`) |
| --- | --- | --- |
| github.com, EMU orgs | default identity from `~/.gitconfig.local` | EMU account |
| github.com, anything else | darthtrevino (noreply email) | darthtrevino |
| gist.github.com | default identity | active gh account |
| `*.ghe.com` | default identity | GHE.com account |
| anything else | default identity | platform default (Git Credential Manager on Windows) |

`shared/git/auth.ps1` signs gh into any missing accounts via the browser, discovers the EMU account's
orgs, and regenerates the `~/.gitconfig.*` files above with the absolute path of gh, so GUI git
clients work without gh on their `PATH`. Re-run it after joining a new EMU org:

```sh
pwsh shared/git/auth.ps1 [-EmuUser jdoe_contoso] [-EmuOrg org1,org2] [-GheHost contoso.ghe.com] [-SkipEmu] [-SkipGhe]
```
